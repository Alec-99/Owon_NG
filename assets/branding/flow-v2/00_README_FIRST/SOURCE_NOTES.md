## Asset notes
- Core vector paths and composition are custom artwork assembled for this kit.
- Inter appears as a *font family reference* in SVG; font files are not included. If a particular target lacks Inter, the fallback is DejaVu Sans. For pixel-perfect reproducibility, use the accompanying rendered PNGs.
- References folder contains only small supplied concept excerpts, explicitly separate from masters.
- Check the project's software and trademark licensing policies before public release.

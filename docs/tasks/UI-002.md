# UI-002 — Guided diagnostic workflows and analysis screens

**Status:** Planned, not authorized until UI-001 review.

Complete **the UI only** for high-quality automotive/electronics testing. Extend searchable/favouritable catalog with groupings for CKP/CMP, Hall/inductive, oxygen narrowband/wideband, MAP/MAF/TPS, injectors, coils, charging, starter, CAN/LIN/ABS, PWM, supplies, ripple, analogue and serial-bus electronics.

Each component test's guided flow should have:
1. Purpose and symptom context.
2. Prerequisites (sensor type, circuit, engine state/bench conditions).
3. Safe connection guidance, required accessories and unavailable/test-blocked cases.
4. Suggested setup/preset with **DEMO** mode visible.
5. Clearly synthetic and source-attributed reference waveform/expected pattern.
6. Comparison UI, notes, measurements and deviations with *non-definitive* suggestions, not diagnosis claims.
7. Save, revisit, print/export a report with source labels.

Add realistic UI for waveform capture history, bookmarks, reference overlays, profile favorites, notes, report building and sessions. Demonstrate full journeys with deterministic fixtures and test them; do not implement validated real diagnostic algorithms, hardware drivers or unsafe procedures. Stop and open PR for review.
